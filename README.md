# To-Do List V2

A To-Do List web application built using HTML, CSS, and JavaScript. This project allows users to create, edit, delete, complete, and filter tasks, with tasks saved using browser Local Storage.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Mark completed tasks as pending
- All / Pending / Completed filters
- Task counter for Total, Completed, and Pending tasks
- Tasks saved using Local Storage
- Tasks remain saved after page refresh
- Press Enter to add a task
- Simple and clean user interface

- Browser Local Storage

## How It Works

Tasks are stored as JavaScript objects containing:

- Task text
- Completion status

The tasks are saved in the browser's Local Storage, allowing them to remain available even after refreshing the page.
